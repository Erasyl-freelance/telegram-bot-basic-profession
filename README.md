# Telegram Bot: Basic Profession Selector 🤖

This is a simple Telegram bot built using `pyTelegramBotAPI`.  
It allows users to select a profession and decide if they're ready for an adventure.  
Great example for learning how inline keyboards and callbacks work.

## Features

- Inline keyboard with 3 professions: Scientist, Musician, Cosmonaut  
- Custom callback responses depending on user choice  
- "Start Over" option to restart the interaction  
- Clean and readable code  

## 🚀 Technologies Used

- Python 3.x
- [pyTelegramBotAPI (Telebot)](https://github.com/eternnoir/pyTelegramBotAPI)
